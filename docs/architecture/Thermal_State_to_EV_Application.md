---

## 3. Original Layer: Intrinsic Thermal Start

The original architecture defines:

### Thermal as State
- Heat can be stored  
- Heat can be triggered  
- Heat can be deployed  

### Thermal as Activation Condition
- System startup depends on temperature readiness  
- Heat acts as a **pre-operational resource**

---

## 4. Transition to EV Application

Electric vehicles reveal a structural limitation:

### Cold-Start Constraint
- Low temperature reduces battery performance  
- Electrical heating consumes limited energy  
- Startup becomes inefficient or fails  

This is a **thermal bootstrap gap**.

---

## 5. EV Interpretation of Thermal Bootstrap

Applying the Thermal Bootstrap System to EV results in:

### Thermal Bootstrap Layer (EV Context)

- Pre-stored or triggerable heat source  
- Localized thermal transfer to battery system  
- Temperature threshold crossing  
- Handoff to electrical systems (BMS / heater / heat pump)
